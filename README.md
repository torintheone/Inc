# Призрак

Стратегия для Android о рабочем движении — в духе Plague Inc и Rebel Inc. Движение зарождается в
одной стране и распространяется по миру, а там, где складывается революционная ситуация, игра
переходит в сражение на карте страны. Полное описание — в [SPEC.md](SPEC.md).

Сейчас готов **этап 0**: карта мира со странами и их показателями. Что изменилось в каждой
версии — в [CHANGELOG.md](CHANGELOG.md).

## Как поставить игру на телефон

1. Открой на телефоне страницу
   [Releases](https://github.com/torintheone/Inc/releases) этого репозитория.
2. В самой верхней версии нажми на файл `prizrak-<версия>.apk` — он скачается.
3. Открой скачанный файл. Android спросит, можно ли устанавливать приложения из этого
   источника (браузера или «Файлов»). Разреши — это нужно один раз.
4. Нажми «Установить». Если появится предупреждение Play Защиты о неизвестном разработчике,
   выбери «Всё равно установить»: игра подписана нашим собственным ключом, а не ключом магазина.
5. Иконка «Призрак» появится среди приложений.

Новые версии ставятся так же, поверх старой: удалять прежнюю не нужно.

## Ключ подписи

Android ставит новую версию поверх старой, только если обе подписаны одним и тем же ключом.
Ключ хранится в секретах GitHub, а не в репозитории: репозиторий публичный, и ключ в нём мог бы
взять кто угодно. Настройка делается один раз:

1. Возьми файл `prizrak-signing-secrets.txt`, который прислал Claude. В нём четыре значения.
   Сохрани копию файла в надёжном месте: без ключа новые версии придётся ставить с удалением старой.
2. Открой в браузере https://github.com/torintheone/Inc/settings/secrets/actions
   (на телефоне — в «версии для ПК»).
3. Нажми **New repository secret**. В поле **Name** впиши `KEYSTORE_BASE64`, в поле **Secret**
   вставь длинную строку из файла. Нажми **Add secret**.
4. Так же добавь ещё три секрета: `KEYSTORE_PASSWORD`, `KEY_ALIAS` и `KEY_PASSWORD`.
5. Напиши Claude «секреты добавлены» — он пересоберёт текущую версию с постоянным ключом.

Пока секретов нет, APK подписывается временным ключом. Он ставится, но перед установкой
следующей версии старую придётся удалить. После перехода на постоянный ключ старую версию тоже
нужно удалить один раз.

## Как поиграть на компьютере (Windows)

На той же странице Releases скачай `prizrak-<версия>-windows.zip`, распакуй и запусти
`Prizrak.exe`. Если Windows покажет «Система Windows защитила ваш компьютер», нажми
«Подробнее» → «Выполнить в любом случае». Карту двигают мышью, приближают колесом.

## Что где лежит

| Папка или файл | Что это |
| --- | --- |
| `SPEC.md` | Техническое задание |
| `ART_LIST.md` | Какие иллюстрации сгенерировать в Grok и как их прислать |
| `art/incoming/` | Сюда загружаются картинки из Grok |
| `data/` | Данные игры в JSON: страны, показатели, позже — события и действия ([описание](data/README.md)) |
| `src/` | Код игры на GDScript |
| `tests/` | Автоматические тесты |
| `tools/` | Скрипты подготовки данных |
| `DECISIONS.md` | Решения, принятые по ходу работы |
| `LICENSES-ASSETS.md` | Источники шрифтов, данных и прочего, их лицензии |

## Как собирается игра

Всё делает GitHub Actions — ничего ставить на компьютер не нужно.

- На каждое изменение запускается сборка «Сборка»: тесты, APK и архив для Windows. Готовые файлы
  лежат на странице запуска во вкладке [Actions](https://github.com/torintheone/Inc/actions),
  в разделе «Artifacts» (нужно войти в GitHub).
- Когда этап готов, ставится тег вроде `v0.0.0` — тогда появляется новая версия в Releases.
- Сборка «Данные мира» заново собирает страны и показатели (`tools/build_world.py`). Её запускают
  вручную: Actions → «Данные мира» → Run workflow.
