# Данные игры

Все данные лежат в JSON-файлах этой папки: игра читает их при запуске, интернет ей не нужен.

| Файл | Что внутри | Кто создаёт |
| --- | --- | --- |
| `world.json` | Страны: названия, показатели, доли классов, зона мир-системы, соседи | `tools/build_world.py` |
| `world_shapes.json` | Полигоны стран для карты | `tools/build_world.py` |
| `links.json` | Связи между странами: торговля, миграция, соседство | `tools/build_world.py` |
| `balance.json` | Все числа модели: цикл, экономика, движение, Реакция, исходы | правится руками |
| `actions.json` | Улучшения движения и действия в стране | правится руками |

Файлы `world*.json` и `links.json` руками не правят: их перезаписывает скрипт.
`balance.json` и `actions.json` — для дизайнера: числа и тексты меняются без программиста.
Перед сборкой их проверяет `python3 tools/validate_data.py` (он же запускается в GitHub Actions):
ссылки между записями, диапазоны значений, тексты для каждого улучшения и действия. Чтобы пересобрать их, запусти
в GitHub вкладку **Actions → «Данные мира» → Run workflow**. Тот же скрипт можно запустить
на компьютере: `pip install -r tools/requirements.txt`, затем `python3 tools/build_world.py`.

## world.json

```json
{
  "version": 1,
  "sources": {"borders": "...", "indicators": "...", "indicators_fetched": "2026-10-25"},
  "map": {"projection": "robinson", "width": 4000, "bounds": [minX, minY, maxX, maxY]},
  "zones": {"core": "ядро", "semi": "полупериферия", "periphery": "периферия"},
  "countries": [ { ...страна... } ]
}
```

Страна:

| Поле | Тип | Смысл |
| --- | --- | --- |
| `id` | строка | Код Natural Earth (`ADM0_A3`), обычно совпадает с ISO 3166 alpha-3: `FRA`, `RUS` |
| `wb_code` | строка или `null` | Код страны у Всемирного банка; `null` — у банка такой страны нет |
| `name_ru`, `name_en` | строка | Название |
| `continent`, `subregion`, `subregion_ru` | строка | Часть света и субрегион по классификации ООН |
| `zone` | `core` / `semi` / `periphery` | Зона мир-системы: ядро, полупериферия, периферия |
| `label` | `[x, y]` | Точка для подписи на карте, в координатах карты |
| `neighbors` | массив `id` | Страны с общей сухопутной границей |
| `indicators` | объект | Показатели, см. ниже |
| `years` | объект | Год, к которому относится каждый показатель |
| `estimated` | массив | Показатели, которых нет у Всемирного банка: они заменены медианой стран той же группы дохода |
| `classes` | объект | Доли восьми классов в населении (в сумме 1), см. ниже |

Показатели (`indicators`):

| Ключ | Код Всемирного банка | Единицы |
| --- | --- | --- |
| `population` | SP.POP.TOTL | человек |
| `gdp_usd` | NY.GDP.MKTP.CD | доллары США |
| `gdp_per_capita` | NY.GDP.PCAP.CD | доллары США на человека |
| `industry_va` | NV.IND.TOTL.ZS | промышленность, % ВВП |
| `emp_agriculture` | SL.AGR.EMPL.ZS | % занятых |
| `emp_industry` | SL.IND.EMPL.ZS | % занятых |
| `emp_services` | SL.SRV.EMPL.ZS | % занятых |
| `wage_workers` | SL.EMP.WORK.ZS | наёмные работники, % занятых |
| `self_employed` | SL.EMP.SELF.ZS | самозанятые, % занятых |
| `unemployment` | SL.UEM.TOTL.ZS | % рабочей силы |
| `gini` | SI.POV.GINI | коэффициент Джини, 0–100 |
| `trade` | NE.TRD.GNFS.ZS | экспорт + импорт, % ВВП |
| `manuf_exports` | TX.VAL.MANF.ZS.UN | промышленные товары, % товарного экспорта |
| `fuel_exports` | TX.VAL.FUEL.ZS.UN | топливо, % товарного экспорта |

| `external_debt` | DT.DOD.DECT.GN.ZS | внешний долг, % ВНД (у богатых стран — 0) |

Доли классов (`classes`) — оценка по структуре занятости Всемирного банка:

| Класс | Ключ | Как оценивается |
| --- | --- | --- |
| Промышленный пролетариат | `industrial_proletariat` | наёмные в промышленности + 30% наёмных в услугах (транспорт, склады, курьеры) |
| Сельский пролетариат, батраки | `rural_proletariat` | наёмные в сельском хозяйстве |
| Крестьянство | `peasantry` | самозанятые в сельском хозяйстве |
| Служащие и интеллигенция | `employees` | 70% наёмных в услугах |
| Мелкая буржуазия | `petty_bourgeoisie` | самозанятые вне сельского хозяйства |
| Крупная буржуазия | `big_bourgeoisie` | 0,3–1% населения, больше в богатых странах |
| Землевладельцы | `landowners` | растёт с долей сельского хозяйства и неравенством |
| Люмпен-пролетариат | `lumpenproletariat` | 40% безработных + 1–3% в зависимости от зоны |

## links.json

`{"links": [{"a": "DEU", "b": "FRA", "trade": 0.72, "migration": 0.93, "neighbor": true, "distance_km": 880}, …]}` —
каждая пара стран один раз. Гравитационная модель: сила связи — произведение экономик (для миграции —
населений), делённое на квадрат расстояния, с поправкой на общую границу; `trade` и `migration` нормированы
к сильнейшей связи каждой из двух стран (0–1). У каждой страны хранятся 8 сильнейших торговых партнёров,
4 миграционных и все соседи.

## balance.json

Все числа модели. Шкалы стран — 0–100, безработица — в процентах, время — в неделях.

| Раздел | Что задаёт |
| --- | --- |
| `time` | Год начала, недель в году, предел партии (50 лет), секунд на неделю при скорости ×1, частота автосохранения |
| `start` | С чего начинается движение в стартовой стране; солидарность в начале |
| `zones` | Базовые уровни надстройки для ядра, полупериферии и периферии; рост сил и чувствительность к кризису |
| `cycle` | Длина цикла (8–10 лет, с противодействием до 11), пять фаз и их влияние на зарплату, безработицу, рост, раскол элит и легитимность; глубина кризисов и её рост; противодействующие тенденции |
| `economy` | Скорости, с которыми показатели тянутся к своим уровням; формула нужды |
| `imperialism` | Перекачка стоимости с периферии и подкуп рабочей аристократии в ядре |
| `superstructure` | Как надстройка отвечает на Реакцию и фашизм |
| `movement` | Рост влияния, сознания и организованности, потери от репрессий, веса классов в базе движения |
| `spread` | Каналы распространения: торговля, миграция, соседство, медиа, революционные страны как пример |
| `revolutionary_situation` | Три условия, порог 70, нужная организованность 50, «окно революции» 10–20 недель |
| `revolution` | Последствия победы и поражения восстания |
| `reaction` | Рост и спад Реакции, меры на порогах 20/40/60/80/100 |
| `solidarity` | Доход солидарности |
| `outcome` | Условия концовок |

Как читаются главные формулы:

- **Нужда** = 0,7 × (100 − зарплата) + 1,6 × безработица + 0,25 × эксплуатация + бедность − 18 (+ рост цен в перегрев).
  Бедность = 35 × (60 − производительные силы) / 60, если силы ниже 60.
- **Восприимчивость** = нужда × (1 − гегемония), обе в долях от 100.
- **Влияние** растёт логистически до потенциала (база движения по классам): рост ∝ восприимчивость ×
  (1 + бонус организованности) × (0,5 + 0,02 × сознание); плюс приток от связей — средняя сила движения у
  партнёров, взвешенная по силе связей.
- **Революционная ситуация** = min(верхи не могут, низы не хотят, активность масс), каждое условие 0–100.

## actions.json

Улучшения (`upgrades`) покупаются один раз и действуют по всему миру:

```json
{"id": "trade_unions", "branch": "organization", "cost": 10, "requires": [],
 "modifiers": {"organization_cap": 30, "organization_rate": 0.5, "visibility": 0.1},
 "unlocks": ["strikes", "consciousness_stage_1"], "on_buy": {"reaction": 5}}
```

- `modifiers` складываются по всем купленным улучшениям: `influence_growth`, `consciousness_rate`,
  `organization_rate`, `visibility`, `migration_channel`, `trade_channel`, `media_channel` — добавки к множителю
  (0,5 = +50%); `organization_cap` — прибавка к потолку организованности в пунктах.
- `unlocks` открывает возможности: `strikes`, `industry_strikes`, стадии сознания `consciousness_stage_1…3`.

Действия в стране (`country_actions`) делаются в выбранной стране и уходят на перезарядку:

```json
{"id": "factory_strike", "cost": 3, "cooldown_weeks": 8,
 "requires": {"unlock": "strikes", "min_influence": 1.0, "min": {"organization": 50}},
 "chance": {"base": 0.6, "terms": {"organization": 0.006}, "phase": {"boom": 0.1},
            "above": [{"field": "unemployment", "value": 15, "add": -0.2}], "flags": {"lessons_of_defeat": 0.08},
            "min": 0.05, "max": 0.92},
 "core_reaction": 0.5,
 "success": {"add": {"real_wage": 2}, "mult": {"influence": 0.95}, "flags": ["strike_won"], "special": "revolution"},
 "failure": {"add": {"organization": -4}}}
```

- Шанс = `base` + Σ `terms[показатель]` × (показатель − 50) + поправка фазы цикла + `above` + `flags`,
  в пределах `min`…`max`.
- `success` / `failure`: `add` — прибавка к показателю страны, `mult` — множитель, `flags` — отметки опыта
  (`strike_won`, `industry_strike_won`), `special` — `revolution` или `defeat` (для восстания).
- `core_reaction` — на сколько растёт Реакция, если действие проведено в стране ядра.

Названия и описания — в `locale/game.csv` (`UPGRADE_<id>`, `UPGRADE_<id>_DESC`, `ACTION_<id>`, …),
их удобнее править в `tools/locale_game.py`.

## world_shapes.json

```json
{
  "version": 1,
  "bounds": [minX, minY, maxX, maxY],
  "countries": {"FRA": [ {полигон}, ... ]},
  "neutral": [ {"id": "GRL", "name_ru": "Гренландия", "name_en": "Greenland", "polygons": [ ... ]} ]
}
```

Полигон — `{"rings": [[x0, y0, x1, y1, ...], [дыра], ...], "tris": [i0, i1, i2, ...]}`.
Первое кольцо — внешний контур, остальные — дыры (например, Лесото внутри ЮАР). `tris` — индексы
вершин треугольников заливки по всем кольцам подряд.

Координаты — проекция Робинсона, ширина карты 4000 единиц, ось Y направлена вниз.
`neutral` — территории с населением меньше 200 тысяч: на карте они серые, выбрать их нельзя.
