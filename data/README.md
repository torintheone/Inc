# Данные игры

Все данные лежат в JSON-файлах этой папки: игра читает их при запуске, интернет ей не нужен.

| Файл | Что внутри | Кто создаёт |
| --- | --- | --- |
| `world.json` | Страны: названия, показатели, доли классов, зона мир-системы, соседи | `tools/build_world.py` |
| `world_shapes.json` | Полигоны стран для карты | `tools/build_world.py` |
| `links.json` | Связи между странами: торговля, миграция, соседство | `tools/build_world.py` |
| `balance.json` | Все числа модели: цикл, экономика, движение, протесты, Реакция, исходы | правится руками |
| `actions.json` | Дерево развития (27 улучшений в пяти ветвях) и действия в стране | правится руками |
| `lines.json` | Пять стратегических линий движения | правится руками |
| `events.json` | События: условия, варианты решений, цепочки | правится руками |
| `battle.json` | Местные сражения: время, силы сторон, действия игрока, ИИ власти, итоги | правится руками |
| `battle_maps.json` | Карты стран для сражений: регионы, соседи, население, объекты | `tools/build_regions.py` |

Файлы `world*.json`, `links.json` и `battle_maps.json` руками не правят: их перезаписывают скрипты.
`balance.json`, `actions.json`, `lines.json`, `events.json` и `battle.json` — для дизайнера: числа и тексты меняются без программиста.
Перед сборкой их проверяет `python3 tools/validate_data.py` (он же запускается в GitHub Actions):
ссылки между записями, диапазоны значений, тексты для каждого улучшения и действия. Чтобы пересобрать их, запусти
в GitHub вкладку **Actions → «Данные мира» → Run workflow**. Тот же скрипт можно запустить
на компьютере: `pip install -r tools/requirements.txt`, затем `python3 tools/build_world.py`.

## world.json

```json
{
  "version": 1,
  "sources": {"borders": "...", "indicators": "...", "indicators_fetched": "2026-10-25"},
  "map": {"projection": "robinson", "width": 4000, "bounds": [minX, minY, maxX, maxY]},
  "zones": {"core": "ядро", "semi": "полупериферия", "periphery": "периферия"},
  "countries": [ { ...страна... } ]
}
```

Страна:

| Поле | Тип | Смысл |
| --- | --- | --- |
| `id` | строка | Код Natural Earth (`ADM0_A3`), обычно совпадает с ISO 3166 alpha-3: `FRA`, `RUS` |
| `wb_code` | строка или `null` | Код страны у Всемирного банка; `null` — у банка такой страны нет |
| `name_ru`, `name_en` | строка | Название |
| `continent`, `subregion`, `subregion_ru` | строка | Часть света и субрегион по классификации ООН |
| `zone` | `core` / `semi` / `periphery` | Зона мир-системы: ядро, полупериферия, периферия |
| `label` | `[x, y]` | Точка для подписи на карте, в координатах карты |
| `neighbors` | массив `id` | Страны с общей сухопутной границей |
| `indicators` | объект | Показатели, см. ниже |
| `years` | объект | Год, к которому относится каждый показатель |
| `estimated` | массив | Показатели, которых нет у Всемирного банка: они заменены медианой стран той же группы дохода |
| `classes` | объект | Доли восьми классов в населении (в сумме 1), см. ниже |

Показатели (`indicators`):

| Ключ | Код Всемирного банка | Единицы |

Доли классов (`classes`) — оценка по структуре занятости Всемирного банка:

| Класс | Ключ | Как оценивается |
| --- | --- | --- |
| Промышленный пролетариат | `industrial_proletariat` | наёмные в промышленности + 30% наёмных в услугах (транспорт, склады, курьеры) |
| Сельский пролетариат, батраки | `rural_proletariat` | наёмные в сельском хозяйстве |
| Крестьянство | `peasantry` | самозанятые в сельском хозяйстве |
| Служащие и интеллигенция | `employees` | 70% наёмных в услугах |
| Мелкая буржуазия | `petty_bourgeoisie` | самозанятые вне сельского хозяйства |
| Крупная буржуазия | `big_bourgeoisie` | 0,3–1% населения, больше в богатых странах |
| Землевладельцы | `landowners` | растёт с долей сельского хозяйства и неравенством |
| Люмпен-пролетариат | `lumpenproletariat` | 40% безработных + 1–3% в зависимости от зоны |

## links.json

`{"links": [{"a": "DEU", "b": "FRA", "trade": 0.72, "migration": 0.93, "neighbor": true, "distance_km": 880}, …]}` —
каждая пара стран один раз. Гравитационная модель: сила связи — произведение экономик (для миграции —
населений), делённое на квадрат расстояния, с поправкой на общую границу; `trade` и `migration` нормированы
к сильнейшей связи каждой из двух стран (0–1). У каждой страны хранятся 8 сильнейших торговых партнёров,
4 миграционных и все соседи.

## balance.json

Все числа модели. Шкалы стран — 0–100, безработица — в процентах, время — в неделях.

| Раздел | Что задаёт |
| --- | --- |
| `time` | Год начала, недель в году, предел партии (20 лет), секунд на неделю при скорости ×1 (2,5), частота автосохранения |
| `start` | С чего начинается движение в стартовой стране; солидарность и кадры в начале |
| `zones` | Базовые уровни надстройки для ядра, полупериферии и периферии; рост сил и чувствительность к кризису |
| `cycle` | Длина цикла (5–7 лет, с противодействием до 7,5), пять фаз и их влияние на зарплату, безработицу, рост, раскол элит, легитимность, частоту протестов (`unrest`) и реформизм; глубина кризисов и её рост; противодействующие тенденции |
| `economy` | Скорости, с которыми показатели тянутся к своим уровням; формула нужды |
| `imperialism` | Перекачка стоимости с периферии и подкуп рабочей аристократии в ядре |
| `superstructure` | Как надстройка отвечает на Реакцию и фашизм |
| `movement` | Рост влияния, сознания и организованности, потери от репрессий, веса классов в базе движения |
| `unrest` | Стихийные протесты: как часто вспыхивают, как быстро их подавляют, что даёт поддержка партии |
| `cadres` | Приток кадров из организованности, сколько кадров держит страна, потери при арестах и разгромах |
| `reformism` | Реформизм по зонам, от рабочей аристократии, скорость |
| `spread` | Каналы распространения: торговля, миграция, соседство, медиа, революционные страны как пример |
| `revolutionary_situation` | Три условия, порог 70, нужная организованность 50, «окно революции» 10–20 недель |
| `revolution` | Последствия победы и поражения восстания |
| `reaction` | Рост и спад Реакции, меры на порогах 20/40/60/80/100 |
| `solidarity` | Постоянный доход солидарности (небольшой взнос и помощь революционных стран) и `upgrade_escalation` — на сколько каждое купленное улучшение дорожает остальные (0,06 = на 6% их цены) |
| `bubbles` | Пузырьки на карте: как часто появляются, сколько дают, сколько живут |
| `events` | Как часто приходят события, сколько недель между ними, когда событие решается само |
| `outcome` | Условия концовок |
| `score` | Очки на экране итогов |

Как читаются главные формулы:

- **Нужда** = 0,7 × (100 − зарплата) + 1,6 × безработица + 0,25 × эксплуатация + бедность − 18 (+ рост цен в перегрев).
  Бедность = 35 × (60 − производительные силы) / 60, если силы ниже 60.
- **Восприимчивость** = нужда × (1 − гегемония), обе в долях от 100.
- **Влияние** растёт логистически до потенциала (база движения по классам): рост ∝ восприимчивость × влияние ×
  (1 + бонус организованности) × (0,5 + 0,02 × сознание); плюс приток от связей — средняя сила движения у
  партнёров, взвешенная по силе связей; плюс стихийное движение, которое вбирает местная организация.
- **Стихийный протест** вспыхивает с шансом `flare_base` × размер страны × (нужда / 50)² × множитель фазы ×
  (1 + 0,02 × влияние). Протест гаснет тем быстрее, чем сильнее репрессии. Над страной появляется пузырёк на
  8 недель: если партия его поддержит, в стране закрепляется движение и появляются кадры; если нет — протест
  подавляют (репрессии +2), разве что местная организация возглавит его сама (шанс = организованность).
- **Кадры** растут на `rate` × организованность / 100 × min(1, влияние / 4) в неделю, до 3 + 0,3 × организованность.
- **Пузырёк солидарности** появляется с шансом 0,04 + 0,003 × √(Σ влияние × размер) в неделю, в стране,
  выбранной пропорционально силе движения, и даёт 1–2 солидарности (не чаще 0,1 раза в неделю).
- **Революционная ситуация** = min(верхи не могут, низы не хотят, активность масс), каждое условие 0–100.

## actions.json

`branches` — пять ветвей дерева развития в порядке показа, `action_groups` — три группы действий.

Улучшения (`upgrades`) покупаются за солидарность один раз и действуют по всему миру. `cost` — начальная цена:
каждое уже купленное улучшение поднимает цены остальных (`solidarity.upgrade_escalation` в `balance.json`).

```json
{"id": "trade_unions", "branch": "organization", "tier": 1, "cost": 8, "requires": ["study_circles"],
 "modifiers": {"organization_cap": 30, "organization_rate": 0.5, "visibility": 0.1},
 "unlocks": ["strikes", "consciousness_stage_1"], "on_buy": {"reaction": 5}}
```

- `branch` и `tier` — место в дереве: колонка-ветвь и ярус сверху вниз. На одном ярусе ветви — не больше двух
  улучшений; требование из той же ветви должно стоять ярусом выше. Требования из другой ветви тоже можно.
- `modifiers` складываются по всем купленным улучшениям и линии. Доли (0,5 = +50%): `influence_growth`,
  `consciousness_rate`, `organization_rate`, `visibility`, `cadre_rate`, каналы `trade_channel`, `migration_channel`,
  `neighbor_channel`, `media_channel`, рост по зонам `core_growth`, `semi_growth`, `periphery_growth`, шансы
  `strike_chance`, `demo_chance`, `uprising_chance`, `uprising_periphery`, и другие. Пункты: `organization_cap`,
  `cadre_cap`, `trust_target`, `reformism`, `activity`, `hegemony_culture`, `army_erosion`. Полный список и как
  каждый показывается игроку — `MOD_KINDS` в `src/ui/ui_text.gd` и строки `MOD_<ключ>` в тексте.
- `unlocks` открывает возможности: действия (`strikes`, `industry_strikes`, `general_strike`, `elections`,
  `army_work`, `factory_seizure`, `solidarity_strike`, `antifascist_defense`) и стадии сознания `consciousness_stage_1…3`.

Действия в стране (`country_actions`) оплачиваются кадрами этой страны и уходят на перерыв:

```json
{"id": "factory_strike", "group": "economic", "tags": ["strike"], "cadres": 2, "cooldown_weeks": 6,
 "requires": {"unlock": "strikes", "min_influence": 1.0, "min": {"organization": 50}},
 "chance": {"base": 0.6, "terms": {"organization": 0.006}, "phase": {"boom": 0.1},
            "above": [{"field": "unemployment", "value": 15, "add": -0.2, "unless": "unemployed_organized"}],
            "flags": {"lessons_of_defeat": 0.08}, "min": 0.05, "max": 0.92},
 "core_reaction": 0.5,
 "success": {"add": {"real_wage": 2, "cadres": 1}, "mult": {"influence": 0.95}, "flags": ["strike_won"],
             "timed": {"port_cells": 104}, "special": "revolution"},
 "failure": {"add": {"organization": -4}, "reaction": 2}}
```

- `cadres` — цена в кадрах страны, `solidarity` — в общей солидарности (у крупных действий и «Прислать
  организаторов»). Школа кадров снижает цену в кадрах, линия — обе цены.
- Шанс = `base` + Σ `terms[показатель]` × (показатель − 50) + поправка фазы цикла + `above` + `flags`,
  плюс модификаторы улучшений для стачек (`tags: ["strike"]`), демонстраций и восстания; в пределах `min`…`max`.
  У правила `above` может быть `unless` — отметка, которая его отменяет.
- `success` / `failure`: `add` — прибавка к показателю страны (в том числе `cadres`), `mult` — множитель,
  `flags` — отметки опыта, `timed` — временные отметки на N недель (`port_cells`, `underground`, `antifascist`,
  `unemployed_organized`), `reaction` — прибавка к Реакции, `special` — `revolution`, `defeat`, `organizers`
  (движение появляется даже там, где его не было) или `solidarity` (поддержка связанных стран).
- `core_reaction` — на сколько растёт Реакция, если действие проведено в стране ядра.
- `art` — имя карточки из `ART_LIST.md`, если оно не `card_<id>`.

Названия и описания — в `locale/game.csv` (`UPGRADE_<id>`, `UPGRADE_<id>_DESC`, `ACTION_<id>`, …),
их удобнее править в `tools/locale_game.py`.

## lines.json

Пять стратегических линий. Игрок выбирает линию в начале партии и может сменить её один раз — тогда
организованность везде умножается на `change_organization_mult` (0,5).

```json
{"id": "syndicalism",
 "modifiers": {"strike_chance": 0.1, "organization_cap": 10, "consciousness_rate": -0.15},
 "action_cost": {"general_strike": 0.6},
 "blocked_actions": ["elections"],
 "requires_override": {"workers_councils": ["trade_unions"]},
 "action_bonus": {"general_strike": {"revolution_chance": 0.35, "min_rev_situation": 55, "min_organization": 40},
                  "elections": {"success_mult": 1.5, "reaction": 2, "add": {"army_loyalty": 4}}}}
```

- `modifiers` — те же ключи, что у улучшений; действуют всю партию.
- `action_cost` — множитель цены действия, `blocked_actions` — недоступные действия.
- `requires_override` — другие требования для улучшения (у рабочих советов — без партии).
- `action_bonus` — что ещё происходит при успехе действия: `success_mult` усиливает прибавки, `reaction` и
  `add` — побочные последствия, `revolution_chance` — шанс, что действие перерастёт в революцию.

Тексты линий — `LINE_<id>`, `LINE_<id>_CURRENT`, `_PLUS`, `_MINUS`, `_WHERE` в `tools/locale_game.py`.

## events.json

События — главный источник разнообразия. Каждое — `id`, категория, условия, вес, перерывы и 2–3 варианта.

```json
{"id": "mass_layoffs", "category": "economy", "scope": "country", "art": "ev_mass_layoffs",
 "weight": 1.0, "cooldown_weeks": 78, "country_cooldown_weeks": 260, "max_times": 2,
 "trigger": {"phase": ["crisis", "depression"], "min": {"unemployment": 9, "influence": 2}},
 "options": [
   {"id": "seize", "requires": {"cadres": 2}, "chance": 0.6,
    "effects": {"country": {"add": {"consciousness": 8, "organization": 3}}},
    "fail": {"country": {"add": {"repression": 5, "cadres": -2}}}},
   {"id": "accept", "default": true, "effects": {"country": {"add": {"trust": -4, "unrest": 8}}}}]}
```

- `scope`: `country` — событие в стране, где есть движение (страну выбирают пропорционально его силе);
  `world` — в мире.
- `category`: `economy`, `state`, `world`, `movement` — подпись в окне события.
- `weight` — вес при выборе (события, которых игрок ещё не видел, втрое вероятнее); у ответных событий
  (`on`) — шанс сработать.
- `cooldown_weeks` — перерыв для события вообще, `country_cooldown_weeks` — для одной страны,
  `max_times` — сколько раз за партию.
- `on` — ответное событие: `action:<действие>`, `action_ok:<действие>`, `action_fail:<действие>`, `crisis_start`,
  `revolution_neighbor` (у соседа победила революция), `defeat` (разгром восстания), `line_change`.
- `chain_only` — событие приходит только как продолжение цепочки.
- `trigger`: `phase`, `phase_week_min`, `reaction_min`, `reaction_max`, `zone`, `min` / `max` (показатели
  страны), `upgrade`, `no_upgrade`, `unlock`, `line`, `flag` / `no_flag`, `timed` / `no_timed` (временные
  отметки), `class_min` (доли классов), `indicator_min` (показатели Всемирного банка), `neighbor_flag_any`,
  `revolutionary` (событие в революционной стране), `any_of` (хотя бы одно из условий).
- Вариант: `requires` — `cadres` (списываются), `solidarity`, `upgrade`, `any_upgrade`, `unlock`, `min`,
  `world.core_consciousness_max`; `chance` — шанс удачи, `effects` — последствия при удаче, `fail` — при
  неудаче; `default` — вариант, который берётся, если решения нет 4 недели (в игре время в это время стоит).
- Последствия: `country`, `movement` (все страны с движением), `core`, `periphery`, `neighbors` — в формате
  исходов действий (`add`, `mult`, `flags`, `timed`, `special`); `reaction`, `solidarity` — общие;
  `chain: {"event": "power_crisis", "after": [8, 16]}` — продолжение через 8–16 недель.
- Временные отметки событий: `emergency` (действия в стране в 1,5 раза дороже), `theory` (сознание гаснет вдвое
  медленнее), `peasant_ally` (влияние растёт в 1,3 раза быстрее), `reformist_cap` (сознание не выше
  политического), `fascist_regime` (репрессии +40, легальности нет), `blockade` (революционная страна вдвое слабее
  распространяет движение и не даёт солидарности).

Названия, тексты и надписи вариантов — `EVENT_<id>`, `EVENT_<id>_TEXT`, `EVENT_<id>_<вариант>` в
`tools/locale_events.py`.

## battle.json

Местное сражение идёт по дням: игрок действует в районах страны, власть отвечает. Разделы:

- `time`: `seconds_per_day` — секунд реального времени на день при обычной скорости; длина сражения —
  оставшиеся недели окна революции × `days_per_window_week`, но не меньше `min_days` и не больше `max_days`.
- `start` — с чего начинается: поддержка в районах (`support_base` + влияние × `support_per_influence` + доля
  горожан × `support_urban` + революционная ситуация × `support_rev_situation`), отряды (`squads_base` +
  организованность × `squads_per_organization` + влияние × `squads_per_influence`), армия (`army_base` +
  лояльность армии страны × `army_per_loyalty`, доля `reserve_share` — в резерве), полиция (репрессии ×
  `police_per_repression`), снабжение и оружие. `spontaneous_penalty` — штраф стихийного восстания.
- `daily` — что происходит каждый день: бои (`combat_rate`, `armed_workers`, `barricade_defense`), снабжение,
  новые агитаторы (`agitator_regen_days`, `agitators_per_council`), пополнение отрядов (`recruit_rate`),
  верность солдат (`loyalty_from_support` выше `loyalty_support_from` % поддержки; ниже `defect_loyalty` часть
  гарнизона, `defect_share`, переходит к революции, а вся армия переходит при средней верности ниже
  `army_defects_loyalty`), доверие масс (`civilian_trust_loss`, `requisition_trust_loss`, `excess_*`, ниже
  `low_trust` поддержка падает везде).
- `ai` — ход власти: переброска войск (`transfer_every_days`, `transfer_share`, `travel_days_per_step`, при
  захваченной железной дороге × `railway_cut_mult`), аресты (`arrest_chance`), арест руководства
  (`leadership_arrest_chance`, новое руководство через `leadership_recover_days`), комендантский час,
  контрпропаганда, добровольцы имущих классов (`volunteers_days`), интервенция при Реакции ≥ `intervention_reaction`.
- `outcome` — итоги: победа — столица и доля промышленных районов `factory_share`; к концу таймера при доле
  страны от `civil_war_min` — гражданская война; её раунд длится `civil_war_round_days` дней раз в
  `civil_war_round_weeks` недель; в раунде доля `civil_war_max` и выше — победа; после `civil_war_max_rounds`
  раундов решает доля `civil_war_final_share`.
- `lines` — бонусы линий в сражении (советы — снабжение, народная война — отряды в деревне, синдикализм — стачки,
  авангард — отряды и защита руководства, массовая партия — города и гарнизоны).
- `actions` — действия игрока:

```json
{"id": "garrison_agitation", "cost": {"agitators": 1}, "cooldown_days": 6, "busy_days": 8, "target": "garrison",
 "chance": 0.45, "loyalty": -10.0, "fail_loyalty": 5.0}
```

`cost` — `agitators` (уходят на задание и возвращаются через `busy_days`), `supplies`, `squads` (нужны в районе),
`solidarity` (из мировой). `cooldown_days` — перерыв, у действий в районе — свой в каждом районе. `target`:
`any` — любой район, `garrison` — где есть гарнизон, `not_power` — спорный или наш, `squads` — где есть наши
отряды, `object:<объект>` — район с объектом, `global` — вся страна. `chance` — базовый шанс, `min_support` —
нужная поддержка. Остальные поля — числа самого действия.

Тексты: `BATTLE_ACTION_<id>`, `BATTLE_ACTION_<id>_DESC`, строки журнала `BATTLE_LOG_<id>_OK` / `_FAIL` — в
`tools/locale_battle.py`.

## battle_maps.json

```json
{"version": 1, "countries": {"FRA": {"regions": [
  {"name_ru": "Лилль", "city": "Лилль", "label": [529.7, 73.9], "population": 3901000, "urban": 0.344,
   "objects": ["factories"], "neighbors": [1, 9, 12], "polygons": [{"rings": [[x0, y0, …]], "tris": [ … ]}]}]}}}
```

В каждой стране 5–20 регионов (8–20 везде, кроме Фиджи). Регионы — административное деление первого уровня
Natural Earth 1:10m; если их больше 20, соседние объединяются (сначала по крупным районам страны), мелкие
присоединяются к соседям, а если регионов меньше 8 — крупные делятся по сторонам света. Заморские территории,
Аляска и Гавайи не входят: остаются регионы, отделённые от основной территории не больше чем на 4°.
Объединённый регион называется по главному городу. Координаты — в прямоугольнике 1000 × 640.

Объекты: `capital` — столица, `factories` — промышленный район (самые городские регионы), `comms` — узел связи
(столица и второй город), `railway` — железнодорожный узел (самые связанные регионы), `port` — порт (по портам
Natural Earth), `arsenal` — арсенал (городской сосед столицы), `agrarian` — аграрный район (горожан меньше 20%).
Население — города Natural Earth плюс сельское по площади.

## world_shapes.json

```json
{
  "version": 1,
  "bounds": [minX, minY, maxX, maxY],
  "countries": {"FRA": [ {полигон}, ... ]},
  "neutral": [ {"id": "GRL", "name_ru": "Гренландия", "name_en": "Greenland", "polygons": [ ... ]} ]
}
```

Полигон — `{"rings": [[x0, y0, x1, y1, ...], [дыра], ...], "tris": [i0, i1, i2, ...]}`.
Первое кольцо — внешний контур, остальные — дыры (например, Лесото внутри ЮАР). `tris` — индексы
вершин треугольников заливки по всем кольцам подряд.

Координаты — проекция Робинсона, ширина карты 4000 единиц, ось Y направлена вниз.
`neutral` — территории с населением меньше 200 тысяч: на карте они серые, выбрать их нельзя.
